# Unidraw: конверсия по типам устройств

**Итоговый проект интенсива по продуктовой аналитике Т-Банка · июль 2026**

## Задача
Исследовать, различается ли конверсия продукта Unidraw в зависимости от типа устройства пользователя (десктоп / мобильные), и предложить продуктовые решения при обнаружении разрыва.

## Что сделано
1. Самостоятельно спроектировала исследование: сформулировала аналитическую задачу и гипотезы
2. Выгрузила и подготовила данные на SQL
3. Проанализировала и визуализировала результаты на Python
4. Сформулировала продуктовые гипотезы о причинах различий и предложения по решениям
5. Защитила результаты перед экспертами интенсива
