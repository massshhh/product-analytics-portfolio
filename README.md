# Аналитика маркетплейса: выручка, города, факторы роста

Учебный проект на датасете маркетплейса (96 заказов, 25 пользователей, июль–октябрь 2026).
Одна и та же задача решена тремя инструментами с взаимной проверкой результатов: SQL → Excel → Python.

## Что сделано
1. **SQL** (SQLite): склейка orders+users (JOIN), выручка по городам (GROUP BY), клиенты с выручкой выше средней (CTE + подзапрос), первые заказы пользователей (ROW_NUMBER + обёртка)
2. **Excel**: подтягивание справочника ВПР/XLOOKUP, сводная таблица «города × месяцы» с группировкой дат, СУММЕСЛИМН/СЧЁТЕСЛИМН, комбинированный график (выручка + средний чек, две оси)
3. **Python (pandas)**: read_excel, merge, groupby, pivot_table, факторный график в matplotlib

## Ключевые результаты
- Общая выручка: 1 625 691 ₽; лидер по городам - Москва (434 583 ₽), далее Казань (415 416 ₽) и Нижний Новгород (287 281 ₽)
- Аномалия: провал выручки Санкт-Петербурга в сентябре (3 582 ₽ против 40–118 тыс. ₽ в другие месяцы)
- **Факторный разбор (октябрь к сентябрю):** выручка +37% (+117,5 тыс. ₽). Количество заказов −36% (вклад −114,3 тыс. ₽), средний чек +114% (вклад +231,8 тыс. ₽). Рост обеспечен фактором среднего чека; причины (структура корзины, крупные заказы) требуют дополнительной проверки
